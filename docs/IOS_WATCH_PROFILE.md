Generate with `python3 scripts/generate_project.py --profile ios-watch`. The result is `QRCatcher-iOS-Watch.xcodeproj`, with parent scheme `QRCatcher` and Watch scheme `QRCatcherWatch`. It contains only the existing three iOS targets and three Watch targets. Parent → Watch uses the existing single dependency and `Embed Watch Content` phase. Mac/TV/Vision targets are excluded. No new phone inbox is created and phone history is not modified. The four existing hosted phone-processor tests remain compiled against the same helper implementations.

No Swift/Objective-C product source, resource, decoder, privacy text, API, persistence or transfer behavior changes in this candidate. The complete current iPhone/iPad source remains c23; this is not a replacement with an old all-platform checkout. Current source version/build remain 1.1 (2) for unsigned package investigation only.
